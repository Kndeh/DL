1Limitasi linear model

Sumber: S01 slide 7 sampai 12, S03 slide 21 sampai 22, catatan kisi-kisi nomor 1, Notion bagian "Limitasi linear model".

Jadi intinya: model linear cuma bisa bikin batas keputusan lurus. Data dunia nyata jarang selurus itu, jadi model linear underfit. Obatnya nonlinearity (activation) plus hidden layer.

Intuisi (versi santai)

  • Bayangin kamu cuma dikasih satu penggaris buat misahin dua kelompok titik di kertas. Kalau kelompoknya emang bisa dipisah satu garis lurus, aman. Kalau kelompoknya melingkar, berselang-seling, atau berlapis, penggarisnya gak cukup, dan itu bukan salah datanya.
  • Model linear itu kekurangan kapasitas, bukan kekurangan data. Makanya error di training set aja udah tinggi. Itu definisi underfitting. (Notion)
  • Jadi kalau di soal ada kata "tidak bisa dipisah garis lurus", otomatis ingat: linear gagal, butuh hidden layer plus activation non-linear.

Mekanisme: kenapa boundary-nya pasti lurus

Perceptron: ŷ = sign(wᵀx + b) (S01 slide 10). Batas antara dua kelas adalah himpunan titik di mana wᵀx + b = 0. Persamaan itu selalu "datar" di ruang inputnya. (Notion)

Arti simbol: x vektor fitur, w bobot (arah tegak lurus boundary), b bias (geser boundary dari titik asal), sign bernilai positif atau negatif tergantung sisi mana titik berada. (arti simbol: tambahan penjelasan geometri standar)

Jebakan ujian (Notion): activation di perceptron tidak membuat boundary melengkung. Threshold tetap dilakukan atas z = wᵀx + b yang linear. Hal yang sama berlaku kalau outputnya sigmoid lalu di-threshold di 0,5.

tambahan Kenapa begitu: σ(z) ≥ 0,5 persis ketika z ≥ 0 (karena σ(0) = 0,5 dan σ naik terus). Jadi batas σ(z) = 0,5 sama dengan batas z = 0, yaitu garis lurus yang sama. Sigmoid cuma mengubah skor jadi probabilitas, bentuk boundary tidak berubah.

XOR: kenapa gak bisa, dibuktikan

XOR menghasilkan 1 kalau input berbeda, 0 kalau sama. Titik (0,0) dan (1,1) kelas 0, titik (0,1) dan (1,0) kelas 1. Kalau digambar, dua titik kelas 1 ada di diagonal berlawanan dari dua titik kelas 0, jadi mau garis horizontal, vertikal, atau diagonal selalu ada titik yang nyasar. (S01 slide 9, Notion)

Bukti aljabar tambahan (biar kamu yakin, bukan buat dihafal). Misal ada w₁, w₂, b yang benar di keempat titik, dengan aturan "kelas 1 kalau z ≥ 0":

  1. (0,0) kelas 0: b < 0
  2. (0,1) kelas 1: w₂ + b ≥ 0
  3. (1,0) kelas 1: w₁ + b ≥ 0
  4. (1,1) kelas 0: w₁ + w₂ + b < 0

Jumlahkan (2) dan (3): w₁ + w₂ + 2b ≥ 0, jadi w₁ + w₂ + b ≥ −b. Karena b < 0, nilai −b positif, sehingga w₁ + w₂ + b > 0. Ini bertabrakan dengan (4). Tidak ada bobot yang memenuhi keempatnya, jadi maksimal 3 dari 4 titik benar. Widget XOR di bawah ngasih bukti visual yang sama.

Widget: coba pisahin XOR dengan satu garis

Pilih gate dan model. Geser bobot sampai semua titik benar. Lingkaran = target 1, kotak = target 0. Titik penuh = tebakan benar, titik kosong = salah. Warna latar = prediksi model di area itu.

Mode MLP memakai bobot buatan tangan (OR dikurangi AND, lalu dibaca sebagai XOR). tambahan Konstruksi ini standar di textbook, bukan dari slide.

Solusi: MLP (hidden layer + activation non-linear)

  1. Tambah hidden layer di antara input dan output. (Notion)
  2. Pasang activation non-linear (sigmoid, tanh, ReLU) di tiap layer buat mematahkan sifat linear. Rumus MLP: z = Wx + b, lalu a = σ(z). (S01 slide 11, Notion)
  3. Boundary jadi kurva. Notion: "dua perceptron menghasilkan dua garis, lalu gabungannya membentuk kurva yang melengkung". Lihat kotak cek ulang di bawah.
  4. Hierarchical features: layer awal menangkap fitur sederhana (tepi), layer dalam menggabungkannya jadi fitur kompleks (bentuk). (Notion, S03 slide 23)

Cek ulang. Teks sumber (Notion): "dua perceptron menghasilkan dua garis, lalu gabungannya membentuk kurva yang melengkung".

tambahan Jawaban standar: kalau activation-nya step atau ReLU, gabungan dua garis menghasilkan region yang dibatasi potongan garis lurus (piecewise linear), belum benar-benar melengkung. Kurva halus muncul kalau activation-nya mulus (sigmoid, tanh) dan atau neuronnya banyak, sehingga potongan-potongan kecil mendekati kurva. Slide S03 slide 22 nulis "decision boundaries become curves, complex regions", jadi di jawaban ujian aman tulis "boundary jadi non-linear (kurva atau region kompleks)".

Contoh hitung 2: tumpukan layer linear tetap linear

tambahan (arah sama dengan S03 slide 22 "power comes from depth and activation").

Layer 1: W₁ = [[1, 2], [0, 1]]. Layer 2: W₂ = [2, 1]. Input x = (3, 1).

Hasilnya sama: dua layer linear = satu layer linear dengan bobot W₂W₁. Tambah 100 layer pun sama, makanya activation wajib ada di antaranya.

Fitur manual vs learned features

  • Trik klasik: nambah x², x³ ke model linear biar kurvanya bisa nyesuaikin. Itu fixed basis function: kamu yang mikir fiturnya. (S01 slide 7, catatan)
  • Masalah 1, tidak scalable: kalau ada 100 fitur dan kamu mau semua suku derajat 3, jumlahnya meledak. tambahan Hitungan: suku derajat 2 saja ada C(101, 2) = 5.050, derajat 3 ada C(102, 3) = 102·101·100 / 6 = 171.700. Itu yang catatan sebut curse of dimensionality.
  • Masalah 2, bergantung domain knowledge dan bias manusia: satu fitur penting kelewat, modelnya jelek. Fitur kaku juga gagal waktu ada variasi baru (posisi miring, cahaya beda, sudut kamera beda). (catatan)
  • Deep learning: fitur dipelajari sendiri dari data mentah, mulai dari tepi, tekstur, sampai bentuk. Deep learning cocok untuk unstructured data (S01 slide 5, 7).

Universal Approximation Theorem: MLP dengan satu hidden layer bisa mengaproksimasi fungsi kontinu apa pun. Di praktik, model yang lebih dalam lebih efisien. (S01 slide 12, Notion: "cukup satu hidden layer?" jawab secara teori cukup, tapi yang dalam lebih efisien)

Jebakan ujian (rangkuman)

  • "Tambah layer tapi tanpa activation" → tetap linear.
  • "Perceptron + sigmoid / threshold" → boundary tetap lurus.
  • "Regresi linear untuk data berbentuk kurva" → underfitting, solusinya fitur non-linear atau MLP.
  • Linear model gagal itu masalah kapasitas (underfitting), bukan overfitting.
  • Universal Approximation Theorem bukan berarti satu hidden layer selalu praktis. Teori cukup, praktik lebih dalam lebih efisien.

Latihan

Soal gaya kisi-kisi

Nomor 1: peneliti pakai model linear + fitur x², x³ untuk prediksi permintaan listrik. Jawaban?

(1) Keterbatasan model linear: cuma bikin batas keputusan lurus (hyperplane), padahal pola nyata melengkung. Fitur x² dan x³ ditambah supaya kurvanya bisa menyesuaikan. Cara ini tidak fleksibel dan susah di-scale: kalau ada 100 fitur, kombinasi manualnya meledak (curse of dimensionality).

(2) Keterbatasan fitur manual (fixed basis functions):

  • Bergantung pada domain knowledge dan bias manusia. Kalau satu fitur penting kelewat, modelnya jelek.
  • Fitur kaku, gagal generalisasi pada variasi baru (posisi miring, cahaya beda, sudut kamera beda).

Pembanding: CNN belajar sendiri dari gambar mentah, mulai dari tepi, tekstur, sampai bentuk. (catatan)

Kenapa single-layer perceptron gagal di XOR, dan bagaimana MLP memperbaikinya?
  1. XOR tidak linearly separable. Perceptron membuat boundary wᵀx + b = 0, yaitu satu garis lurus, sehingga paling banyak 3 dari 4 titik benar.
  2. MLP menambah hidden layer dengan activation non-linear. Hidden neuron pertama jadi detektor OR, kedua detektor AND, output mengambil "OR tapi bukan AND".
  3. Hidden layer mengubah representasi input sampai kelasnya bisa dipisah linear di ruang hidden, dan fitur dipelajari berlapis (sederhana ke kompleks).
  4. Tanpa activation, tumpukan layer tetap satu transformasi linear, jadi activation non-linear wajib.

    Optimization dan gradient descent

    Intuisi. Bayangin kamu di gunung berkabut dan mau turun ke lembah (loss paling kecil). Kamu gak lihat peta, tapi bisa rasain kemiringan tanah di bawah kaki. Tiap langkah, kamu melangkah ke arah yang paling menurun. Itu gradient descent. (analogi: tambahan)

    Mekanisme. Optimization = minimalin loss function dengan nyetel weights dan bias secara iteratif (S02 slide 6). Tujuannya cari bobot dan bias θ yang bikin tebakan model di putaran berikutnya makin dekat ke kebenaran. (Notion)

    Update ruleArti simbol
    θ ← θ − η ∇θ L (S02 slide 7)θ = parameter (weights dan bias). η = learning rate (ukuran langkah). L = loss. ∇θ L = gradient loss terhadap θ.

    Kenapa tanda minus? Gradien menunjuk ke arah loss naik paling cepat. Kita mau loss turun, jadi melangkah berlawanan arah gradien, makanya minus. (Notion) Kalau salah ketik jadi plus, model malah naik gunung.

    Contoh hitung tambahan (fungsi mainan L(θ) = θ², gradien 2θ, mulai θ = 3, jadi L = 9).

    • η = 0,1: gradien = 6, θ₁ = 3 − 0,1·6 = 2,4. Gradien = 4,8, θ₂ = 2,4 − 0,48 = 1,92. Mendekati 0, benar.
    • Tanda salah (plus), η = 0,1: θ₁ = 3 + 0,6 = 3,6, L = 12,96 > 9. Loss naik, bukan turun.
    • η terlalu besar = 1,1: gradien 6, θ₁ = 3 − 1,1·6 = −3,6. Gradien = −7,2, θ₂ = −3,6 + 7,92 = 4,32. Nilai |θ| membesar 3 → 3,6 → 4,32 (dikali 1,2 tiap langkah), loss diverge. Rumus umumnya θ ← (1 − 2η)θ, jadi stabil kalau |1 − 2η| < 1, yaitu 0 < η < 1.

    Fungsi mainan tambahan: L(θ) = θ², gradien = 2θ, mulai dari θ = 3. Ubah learning rate dan tanda update, lihat apakah loss turun.

Contoh: gradien konstan g = 1, β = 0,9 → v₁ = 1, v₂ = 0,9·1 + 1 = 1,9, v₃ = 0,9·1,9 + 1 = 2,71.     Initialization

    Intuisi. Init itu titik awal pendakian. Titik awal jelek bikin training lambat atau gagal total. Tujuannya jaga activation dan gradient tetap di rentang wajar, hindari saturasi dan exploding activations. (S02 slide 16, Notion)

    • Saturasi dan vanishing gradient. Kurva sigmoid berbentuk S dan di ujung atas atau bawahnya sangat datar. Bobot awal terlalu besar melempar input ke ujung datar itu (saturasi). Gradien dihitung dari kemiringan kurva, jadi di sana gradiennya hampir nol, dan lapisan-lapisan awal berhenti belajar. (Notion, S01 slide 19)
    • Exploding activations. Bobot awal terlalu besar, tiap layer mengalikan dengan angka besar terus-menerus, nilainya meledak sampai overflow, training hancur. (Notion, S01 slide 20)

    Contoh hitung tambahan (turunan sigmoid σ'(z) = σ(z)(1 − σ(z)), nilai maksimumnya 0,25).

    • z = 0: σ' = 0,5 · 0,5 = 0,25. z = 5: σ = 0,9933, σ' ≈ 0,0066. z = 10: σ' ≈ 0,000045. Makin saturasi, gradien makin mati.
    • Rantai 10 layer sigmoid, kasus terbaik tiap layer 0,25: 0,25¹⁰ ≈ 9,5 × 10⁻⁷. Gradien yang sampai ke layer pertama tinggal sepersejuta, itu vanishing gradient.

    Overfitting

    Intuisi. Overfit itu anak yang ngapalin kunci jawaban latihan soal, tapi bingung waktu soal ujiannya beda. Model belajar noise atau pola tidak relevan (S02 slide 20), biasanya karena terlalu kompleks untuk jumlah data. (Notion)

    Tandanya: training loss terus turun, validation loss naik. Kuncinya ada di gap, bukan di nilai training loss yang kecil. (Notion, S01 slide 21)

    Regularization

    Definisi. Regularisasi = teknik yang membatasi kompleksitas model supaya tidak menghafal data training dan bisa generalisasi ke data baru. Slide menyebut empat teknik: L2, dropout, data augmentation, early stopping. L1 ditambahkan karena sering muncul di ujian. (Notion)

    L2 dan L1: simbol dan kenapa bekerja

    SimbolArti
    LLoss awal (misal BCE atau MSE)
    λKekuatan regularisasi (hyperparameter)
    Σ w²Jumlah kuadrat semua bobot

    Bobot besar dihukum, jadi model memilih bobot kecil yang lebih halus dan kurang kompleks. (Notion, "ada di kisi-kisi salah satu dosen")

    Contoh hitung tambahan. Bobot w = (3, −4), λ = 0,01, loss awal L = 0,5.

    • Σw² = 9 + 16 = 25. Penalti = 0,01 · 25 = 0,25. L_new = 0,5 + 0,25 = 0,75.
    • Kenapa disebut weight decay: gradien penalti terhadap w adalah 2λw, jadi update menjadi w ← w − η(∂L/∂w + 2λw). Bagian bobot menyusut tiap langkah dengan faktor 1 − 2ηλ. Untuk η = 0,1 dan λ = 0,01, faktornya 1 − 0,002 = 0,998.
    • L1: Σ|w| = 3 + 4 = 7, penalti = 0,07. Gradien penalti λ·sign(w) konstan, jadi bobot kecil bisa didorong sampai tepat nol (itu sebab L1 menghasilkan model sparse).

    Dropout, augmentation, early stopping: detail yang sering ditanya

    • Hanya saat training. Dropout dan augmentation aktif di training. Saat evaluasi, semua neuron aktif dan validation/test tidak diaugmentasi. (S02 slide 22 sampai 23, catatan)
    • Cara kerja dropout (tambahan): PyTorch biasanya pakai inverted dropout, output dikali 1/(1−p) saat training supaya skala tetap. Contoh p = 0,5: aktivasi [1, 2, 3, 4], mask [1, 0, 1, 0], hasil [2, 0, 6, 0]. Jadi saat evaluasi tidak perlu penyesuaian. (catatan)
    • Early stopping (tambahan): biasanya pakai patience (berapa epoch menunggu) dan simpan checkpoint model terbaik. Notion: "simpan model terbaik sebelum validation loss naik".

    Contoh jawaban essay (kerangka Notion)

    Soal: "Model CNN untuk klasifikasi penyakit daun menunjukkan training loss turun hingga 0,05, tetapi validation loss naik sejak epoch 10. Analisis masalahnya dan berikan solusinya."

    1. Diagnosis: training loss turun dan validation loss naik → overfitting.
    2. Penyebab: model terlalu kompleks atau data terlalu sedikit untuk menggeneralisasi.
    3. Solusi:
      • Early stopping di sekitar epoch 10, dengan menyimpan checkpoint terbaik.
      • Data augmentation (rotasi, flip, crop) hanya pada data training.
      • Dropout 0,2 sampai 0,5, atau L2 dengan λ yang wajar.
    4. Evaluasi: ukur dengan validation dan test set, pilih metrik sesuai kelas (misal F1 kalau kelas tidak seimbang).

    Cek ulang. Teks sumber (Notion): "Early stopping di epoch 10, dengan menyimpan checkpoint terbaik", padahal soalnya bilang validation loss naik sejak epoch 10.

    tambahan Jawaban standar: checkpoint terbaik adalah epoch dengan validation loss terendah, yaitu sekitar epoch 9 sampai 10 (sebelum mulai naik). Dengan patience, training baru benar-benar berhenti beberapa epoch setelahnya, lalu bobot dikembalikan ke checkpoint terbaik. Di jawaban tulis "berhenti sekitar epoch 10 dan pakai checkpoint dengan validation loss terendah".

    Jebakan ujian (rangkuman topik 2)

    • Tanda minus di update rule: gradien menunjuk ke arah naik.
    • Xavier untuk sigmoid/tanh, He untuk ReLU. Jangan kebalik.
    • Dropout dan augmentation hanya saat training.
    • Accuracy tinggi belum tentu bagus kalau imbalance.
    • MAE lebih tahan outlier, MSE menghukum error besar.
    • Dying ReLU tidak pulih sendiri.

    Latihan

    Soal gaya kisi-kisi

    Jelaskan tiga cara mengurangi overfitting dan kapan masing-masing dipakai.
    1. L2 regularization: tambah penalti λΣw² ke loss supaya bobot kecil. Dipakai saat bobot membesar atau model terlalu kompleks. Hati-hati, λ terlalu besar bikin underfitting.
    2. Dropout: matikan neuron acak saat training (0,2 sampai 0,5). Dipakai di jaringan dalam. Mencegah co-adaptation.
    3. Early stopping: stop saat validation loss mulai naik. Selalu bisa dipakai, butuh validation set yang baik.

    Tambahan lain dari slide: data augmentation untuk data gambar yang sedikit.

    Bandingkan SGD, Momentum, RMSProp, dan Adam.

    SGD: update dasar, simple, sensitif ke LR, dipilih kalau mau kontrol dan regularisasi. Momentum: nambah velocity, konvergen lebih cepat, perlu tuning, cocok problem convex. RMSProp: skala LR dari riwayat gradient, stabil, sering untuk RNN. Adam: gabungan Momentum dan RMSProp, adaptif dan populer sebagai default, tapi bisa overfit.

    Kenapa learning rate yang terlalu tinggi dan terlalu rendah sama-sama bermasalah? Apa solusinya?

    Terlalu tinggi: langkah kelewat jauh, loss melompat atau diverge. Terlalu rendah: konvergensi sangat lambat. Solusi: learning rate schedule (step decay, exponential decay, cosine annealing, reduce on plateau), atau pakai optimizer adaptif seperti Adam.

    Dataset 95% kelas A. Model selalu menebak A dan accuracy 95%. Apa masalahnya dan solusinya?

    Class imbalance: accuracy menipu karena model tidak menangkap kelas minoritas sama sekali (recall minoritas 0). Pakai precision, recall, F1, dan tangani imbalance dengan class weights atau sampling.

      Dari mana rumus-rumus itu muncul tambahan

      Bagian ini penjelasan turunan standar, bukan dari slide. Tujuannya biar rumus masuk akal, bukan sekadar hafalan.

      1. Ukuran output: hitung berapa kali kernel bisa "mendarat"

      1. Setelah padding, lebar efektif input = W + 2P (nol ditambah di kiri dan kanan).
      2. Kernel selebar F menempati posisi mulai dari 0. Posisi mulai terakhir yang masih muat adalah W + 2P − F.
      3. Kernel bergeser tiap S piksel, jadi posisi mulainya 0, S, 2S, ... Banyak posisi = ⌊(W + 2P − F) / S⌋ + 1. Angka "+1" muncul karena posisi pertama (0) ikut dihitung.
      4. Kalau (W + 2P − F) tidak habis dibagi S, sisa piksel di ujung tidak cukup buat satu posisi penuh, makanya dibulatkan ke bawah (floor).

      2. Kenapa P = (F − 1) / 2 menjaga ukuran saat S = 1

      Mau output = input, jadi W − F + 2P + 1 = W. Sederhanakan: 2P = F − 1, sehingga P = (F − 1) / 2. Untuk F = 3, P = 1. Untuk F = 5, P = 2. Untuk F genap, P-nya pecahan, makanya same padding ideal dengan kernel ganjil.

      3. Kenapa parameter = (F × F × C_in + 1) × K

      • Satu filter harus menutupi semua channel input, jadi bentuknya F × F × C_in. Itu weights per filter.
      • Tiap filter punya satu bias (satu angka yang ditambahkan ke seluruh feature map-nya). Jadi parameter per filter = F·F·C_in + 1.
      • Ada K filter, tiap filter menghasilkan satu feature map. Maka channel output = K dan total parameter = (F·F·C_in + 1) × K.
      • Ukuran gambar (W, H) tidak muncul di rumus parameter. Itu karena bobot dipakai ulang di semua posisi (shared weights). Gambar lebih besar berarti output lebih besar, bukan parameter lebih banyak.

      4. Receptive field: seberapa luas "pandangan" satu neuron

      Satu piksel output dari kernel 3×3 melihat area 3×3 di input. Kalau ditumpuk satu conv 3×3 lagi (stride 1), tiap neuron di layer kedua melihat 3×3 neuron layer pertama, yang masing-masing melihat 3×3 input, jadi gabungannya 5×5. Tiga layer: 7×7. Untuk stride 1: RF = 1 + n × (F − 1) dengan n = jumlah layer conv.

      Inilah alasan VGG cuma pakai conv 3×3 (S04 slide 17, VGG hanya conv 3×3 dan pooling 2×2): tiga conv 3×3 melihat area sama dengan satu conv 7×7, tapi dengan parameter lebih sedikit. Dengan C = 64 channel (tanpa bias): tiga layer 3×3 = 3 × (3 × 3 × 64 × 64) = 110.592 parameter, satu layer 7×7 = 7 × 7 × 64 × 64 = 200.704 parameter. Plus ada ReLU tambahan di antaranya, jadi lebih ekspresif.

          Training loop (S07 slide 11, dari gambar kode)

          LangkahKode di slideArtinya

          Urutan update dalam satu iterasi (Notion)

          1. Ambil batch data real (label 1).
          2. Buat noise acak z, masukkan ke G untuk menghasilkan fake (label 0 untuk D).
          3. Update D: hitung loss D dari real dan fake (fake di-detach), lalu update hanya bobot D.
          4. Update G: bekukan (freeze) bobot D, hitung loss G dari output D terhadap fake (label 1), lalu update hanya bobot G.

          Ringkasnya: real batch → noise → fake (detach) → update D saja → freeze D → update G saja. Klik tombol di widget untuk melihat siapa yang dilatih di tiap langkah.

          Widget: urutan update GAN dalam satu iterasi

          Klik "Langkah berikutnya". Kotak berwarna "dilatih" = bobot yang di-update di langkah itu, kotak putus-putus "frozen" = tidak di-update.

          tambahan Di PyTorch biasanya "freeze D" dilakukan dengan memakai dua optimizer terpisah: optimizer D hanya memegang parameter D, optimizer G hanya parameter G. Pada langkah G, gradient tetap mengalir melalui D ke G, tapi hanya optimizer_G.step() yang mengubah bobot.

          Kenapa G pakai label 1 (non-saturating loss) tambahan

          Versi minimax asli meminta G meminimalkan log(1 − D(G(z))). Masalahnya, di awal training D(G(z)) dekat 0 (D gampang mengenali fake), dan di sana gradien versi itu hampir nol. Bandingkan di level logit a dengan D = σ(a):

          • Versi minimax: turunan log(1 − σ(a)) terhadap a = −σ(a). Saat D(G(z)) = 0,01 besarnya cuma 0,01.
          • Versi non-saturating −log σ(a): turunannya −(1 − σ(a)). Saat D(G(z)) = 0,01 besarnya 0,99.

          Jadi G tetap dapat sinyal kuat justru saat sedang kalah. Loss G di slide 10 (−E[log D(G(z))]) sudah bentuk non-saturating ini. Notion menyebutnya "non-saturating loss" untuk G.

          Kenapa evaluasi GAN sulit dan bagaimana mengatasinya?

            Apa itu MLP

            Intuisi. MLP (Multi-Layer Perceptron) itu tumpukan "linear lalu non-linear". Tiap neuron menimbang semua input, lalu activation memutuskan seberapa kuat dia "menyala". Hidden layer belajar kombinasi fitur, output layer menerjemahkan jadi jawaban sesuai tugas. (Notion, S03 slide 22 sampai 23)

            Mekanisme dan rumus: z = Wx + b, lalu a = σ(z) (S01 slide 11, Notion). MLP adalah jaringan feedforward dengan input layer, satu atau lebih hidden layer, dan output layer, di mana tiap neuron terhubung penuh ke neuron layer berikutnya (fully connected). (Notion)

            KomponenFungsi
            Input layerMenerima fitur
            Hidden layer(s)Mempelajari kombinasi fitur, lewat activation non-linear
            Output layerMenghasilkan prediksi sesuai tugas

            Contoh hitung forward pass tambahan (angka buatan sendiri). Jaringan 2 → 2 → 1, hidden pakai ReLU.

            • Input x = (2, 1). Bobot hidden W₁ = [[1, −1], [0,5, 2]], bias b₁ = (0, −1).
            • z₁ = W₁x + b₁ = (1·2 + (−1)·1 + 0, 0,5·2 + 2·1 − 1) = (1, 2). ReLU: a₁ = (1, 2).
            • Output w₂ = (1, −0,5), b₂ = 0,3: z₂ = 1·1 + (−0,5)·2 + 0,3 = 0,3.
            • Regresi: ŷ = 0,3 (tanpa activation). Klasifikasi biner: ŷ = σ(0,3) = 1 / (1 + e^(−0,3)) = 0,5744, dengan threshold 0,5 diprediksi kelas 1.
            • Jumlah parameter: (2·2 + 2) + (2·1 + 1) = 6 + 3 = 9.

            Kegunaan MLP dan kapan pakai

            • Data tabular (baris dan kolom fitur). Ini kandang MLP. (S04 slide 33: MLP use case = tabular)
            • Klasifikasi (biner atau multiklas) dan regresi (nilai kontinu).
            • Pendekatan fungsi non-linear: menurut Universal Approximation Theorem, MLP dengan satu hidden layer bisa mengaproksimasi fungsi kontinu apa pun. (S01 slide 12, Notion)
            • Dataset sederhana seperti MNIST: angka tulisan tangan 28×28 piksel, 10 kelas, MLP mencapai akurasi sekitar 97%. (S01 slide 25, Notion)

              • Sigmoid + BCELoss boleh, tapi BCEWithLogitsLoss lebih disarankan (lebih stabil numerik).
              • Regresi: output tanpa activation. Sigmoid di regresi membatasi hasil ke (0, 1).
              • MSE untuk klasifikasi? Salah pasangan. Klasifikasi pakai cross entropy.
              • Accuracy 90%+ di data imbalance belum berarti model bagus.
              • Train 99% vs validation 70% = overfitting. Train 60% dan validation 58% = underfitting.

              Apa keterbatasan MLP untuk gambar dan apa solusinya?

              MLP tidak memahami struktur spasial karena tiap piksel diperlakukan sebagai fitur terpisah, sehingga parameter membengkak dan rentan overfit. Solusinya CNN, yang memakai spatial locality dan shared weights lewat kernel.

                Intuisi

                • Bayangin kamu disuruh meringkas satu bab buku jadi tiga kalimat, lalu temanmu disuruh menulis ulang bab itu cuma dari tiga kalimat tadi. Kalau hasil tulis ulangnya mirip, berarti ringkasanmu memuat hal penting. Itu autoencoder: encoder meringkas, latent adalah ringkasannya, decoder menulis ulang. (analogi: tambahan)
                • Targetnya input itu sendiri, jadi tidak perlu label. Itu kenapa disebut unsupervised. (S06 slide 6, catatan)
                • Karena latent lebih kecil dari input, model dipaksa menyimpan hanya fitur yang paling penting. Itu yang disebut representation learning.

                Rumus loss dan artinya

                • Reconstruction loss (MSE): L = (1/n) Σ (xᵢ − x̂ᵢ)² (S06 slide 8). xᵢ = nilai input asli, x̂ᵢ = hasil rekonstruksi, n = jumlah elemen. BCE dipakai untuk piksel di rentang [0, 1]. (catatan)
                • Tujuan: minimalkan reconstruction error, sehingga latent menyimpan informasi penting.

                Contoh hitung loss tambahan. Input x = (0,2; 0,8; 0,5), rekonstruksi x̂ = (0,3; 0,6; 0,5).

                • Selisih x − x̂ = (−0,1; 0,2; 0). Kuadrat = (0,01; 0,04; 0). Jumlah = 0,05.
                • MSE = 0,05 / 3 = 0,0167.

                Contoh ukuran parameter (arsitektur dari kode slide 12, 784 → 128 → 32 → 128 → 784, FC = in × out + out):

                • Encoder: 784·128 + 128 = 100.480, lalu 128·32 + 32 = 4.128.
                • Decoder: 32·128 + 128 = 4.224, lalu 128·784 + 784 = 101.136.
                • Total = 100.480 + 4.128 + 4.224 + 101.136 = 209.968. Rasio kompresi = 784 / 32 = 24,5 kali.
                • Versi catatan (784 → 256 → 32 → 256 → 784): 200.960 + 8.224 + 8.448 + 201.488 = 419.120.

                Dipakai untuk apa

                • Reduksi dimensi (seperti PCA tapi nonlinear).
                • Denoising input yang rusak.
                • Anomaly detection: error lebih tinggi pada data tidak biasa.
                • Generative modeling (lewat VAE).
                • Pencarian gambar mirip lewat kemiripan latent vector. (S06 slide 9, 26, 27)

                Arsitektur vs tipe: bedanya apa

                Arsitektur = bentuk jaringan. Berapa besar latent dibanding input, simetris atau tidak, jenis layer.

                Tipe = ide atau trik training. Ada noise atau tidak, ada penalti sparsity atau tidak, latent berupa titik atau distribusi.

                Jadi "undercomplete" itu bentuk arsitektur, sedangkan "denoising" itu tipe.

                Bentuk arsitekturLatent vs inputEfek
                UndercompleteLatent lebih kecilMemaksa kompresi, fitur penting tersimpan. Bentuk dasar vanilla.
                OvercompleteLatent lebih besar atau samaBerisiko cuma menyalin input. Perlu bantuan sparsity atau denoising.

                Kenapa overcomplete bisa "copy"? Kalau latent punya ruang sebesar input, jaringan bisa belajar fungsi identitas (output = input) dengan loss mendekati nol tanpa belajar struktur apa pun. Latent kecil mencegah itu karena informasi tidak muat semua. (catatan: model jadi "malas berpikir"; penjelasan identitas: tambahan) Slide menyebut "avoid overcomplete latent space" dan "latent space too large → just copy input". (S06 slide 30, 31)

                Harus simetris? Tidak harus. Simetri itu kebiasaan ("typically" di slide 11). Yang wajib: output decoder berdimensi sama dengan input. Kedalaman, lebar, dan jenis layer encoder dan decoder boleh beda. Contoh: encoder Conv + Pooling, decoder ConvTranspose atau Upsampling tambahan. Contoh asimetris valid: encoder 784 → 256 → 32, decoder cukup 32 → 784 dengan satu layer. Kalau ditanya, jawab "tidak harus, tapi umumnya simetris karena lebih mudah dirancang dan diseimbangkan". (S06 slide 11, catatan)

                Denoising

                Kode slide 16: x_noisy = x + noise, output = model(x_noisy), loss = mse_loss(output, x). Perhatikan: input berisik, tapi loss dibandingkan dengan x bersih. Itu inti denoising: model belajar membuang noise, bukan menyalinnya. Representasi jadi lebih tahan noise. (slide 15, 16)

                Contoh hitung tambahan. x = (0,2; 0,8), noise = (0,1; −0,2), jadi x_noisy = (0,3; 0,6). Misal output model = (0,25; 0,75).

                • Loss ke x bersih: ((0,25 − 0,2)² + (0,75 − 0,8)²) / 2 = (0,0025 + 0,0025) / 2 = 0,0025.
                • Kalau salah dibandingkan ke x_noisy: ((0,25 − 0,3)² + (0,75 − 0,6)²) / 2 = (0,0025 + 0,0225) / 2 = 0,0125. Model malah dihukum karena membuang noise.

                Sparse

                Penalti L_total = L_reconstruction + λ|z|₁ (slide 19). |z|₁ adalah jumlah nilai absolut elemen latent, λ mengatur kuatnya penalti. Efeknya hanya sedikit neuron latent yang aktif, meniru neuron biologis yang kebanyakan diam, dan membantu fitur disentangled dan interpretable (slide 18). Catatan menyebut penalti umumnya L1.

                Contoh hitung tambahan. z = (0; 0,5; 0; −0,3; 0), jadi |z|₁ = 0,8. λ = 0,1 → penalti = 0,08. L_recon = 0,05 → L_total = 0,05 + 0,08 = 0,13. Model dapat mengurangi loss dengan mendorong elemen z ke 0.

                VAE

                • Motivasi: bikin latent space kontinu dan generatif. Belajar menyampel dari distribusi, bukan satu titik. Memungkinkan interpolasi halus dan generasi data. (slide 21)
                • Latent: z = μ + σ·ε, ε ~ N(0,1). Encoder mengeluarkan μ dan σ (atau log-variance), decoder menerima z. (slide 22)
                • Loss slide 23: L = E(|x − x̂|²) + D_KL(q(z|x) ‖ p(z)). Bacanya: rekonstruksi plus jarak distribusi latent ke prior. (slide 23; di teks ekstraksi tertulis q(z, x), dibaca sebagai q(z|x))
                • Kode slide 24: mu, logvar = encoder(x), std = torch.exp(0.5 * logvar), eps = torch.randn_like(std), z = mu + eps * std, output = decoder(z). Jadi encoder mengeluarkan log-variance, bukan σ langsung.

                Contoh hitung tambahan. μ = 0,5, σ = 0,2 (jadi variance 0,04, logvar = ln 0,04 = −3,2189), ε = −1.

                • std = exp(0,5 · logvar) = exp(−1,6094) = 0,2. Cocok dengan σ.
                • z = μ + ε · std = 0,5 + (−1)(0,2) = 0,3.
                • KL ke N(0,1), bentuk tertutup Gaussian ½(σ² + μ² − 1 − ln σ²) = ½(0,04 + 0,25 − 1 + 3,2189) = ½ · 2,5089 = 1,2544.

                Kenapa z ditulis μ + σ·ε? Mengambil sampel langsung dari N(μ, σ²) tidak bisa dilewati gradient. Dengan memindahkan keacakan ke ε (yang tidak punya parameter), z menjadi fungsi mulus dari μ dan σ, jadi backprop bisa menyentuh encoder. (alasan: tambahan, standar textbook, slide cuma menulis rumusnya)

                Latihan

                Soal gaya kisi-kisi

                Pabrik mau deteksi sensor rusak tanpa data berlabel. Rancang arsitektur autoencoder dan pilih tipenya.
                1. Model: autoencoder, karena data tidak berlabel (unsupervised).
                2. Tipe: vanilla, atau denoising kalau data sensor sering berisik.
                3. Arsitektur: encoder kompres input ke latent kecil (undercomplete), decoder rekonstruksi input. Simetris itu umum tapi tidak wajib.
                4. Training: latih hanya pada data normal dengan reconstruction loss, pantau validation loss.
                5. Deteksi: data dengan reconstruction error di atas threshold dianggap anomali.

                tambahan Threshold sering ditentukan dari distribusi error data normal, misal mean + 3 × std. Contoh: error normal rata-rata 0,016 dengan std 0,004 → threshold = 0,016 + 3 × 0,004 = 0,028. Sensor dengan error 0,4 jelas anomali.

                Jelaskan perbedaan undercomplete dan overcomplete, dan kenapa overcomplete berisiko.

                Undercomplete: latent lebih kecil dari input, memaksa kompresi sehingga fitur penting tersimpan. Overcomplete: latent lebih besar atau sama dengan input, berisiko cuma menyalin input tanpa belajar. Perlu bantuan sparsity atau denoising.

                Apa beda denoising, sparse, dan VAE?

                Denoising: input diberi noise, target tetap bersih, representasi tahan noise. Sparse: penalti λ|z|₁ pada latent supaya hanya sedikit neuron aktif, fitur interpretable, boleh overcomplete. VAE: latent berupa distribusi (z = μ + σ·ε), loss reconstruction + KL divergence, bisa generate dan interpolasi.
